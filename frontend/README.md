# 🩺 CareMate - AI Symptom Checker

A full-stack AI-based symptom checker that predicts diseases based on user input.

## 🚀 Features
- AI-based disease prediction
- Symptom-based input system
- Confidence scoring
- Severity calculation
- Precautions and description
- History tracking with MongoDB

## 🛠 Tech Stack
- Frontend: React.js
- Backend: Node.js, Express
- Database: MongoDB Atlas
- AI Model: Python (Naive Bayes)

## ⚠️ Disclaimer
This is not a medical diagnosis system. It provides preliminary predictions only.
